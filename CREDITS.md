# Credits

The planet surfaces are real NASA imagery (public domain, see below). Everything else visible on this site — the
atmospheres, starfield, nebula, flight streaks, the cruiser, Phobos, the poster and the favicon — is generated by
code written for this project. The social preview image (`src/app/opengraph-image.png`, `twitter-image.png`) is a
screenshot of this site itself. No third-party 3D models or HDRIs are used. The cruiser's reflections come from
three.js's `RoomEnvironment` (a scene built in code, MIT) and its solar-cell texture is generated at start-up.

## NASA imagery (public domain — US Government work, NASA media usage guidelines)

graded and packed into WebP (colour + an extra channel) for this site; NASA does not endorse this project.
